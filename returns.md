# Returns — BrightByte Electronics

BrightByte Electronics is a fictional electronics shop. All information in this document is sample data for learning.

## Return window
Customers can request a return within 30 calendar days of delivery.

## Return conditions
The item must be undamaged and include all original accessories. Opened items are eligible if they meet these conditions. Original packaging is recommended but not required.

## How to request a return
Provide your order ID and confirm whether the item is undamaged and all original accessories are included. The shop must approve the return before you send the item back.

## Return shipping and refunds
For a change-of-mind return, return shipping costs €5, deducted from the refund. If an item arrived defective or the wrong item was delivered, the shop pays return shipping.

Refunds go to the original payment method within 5 business days after the returned item is received and inspected. Original delivery charges are not refunded for change-of-mind returns.
